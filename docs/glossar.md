# Glossar – Ubiquitous Language

Die Begriffe verwenden wir im Gespräch, in der Dokumentation und im Code. Wir schärfen ihre Bedeutung beim Modellieren.

## Nutzerprofil

Nutzerprofil ist der vorläufige Bounded Context für die Profildaten einer Person in Knitventure.

| Begriff | Bedeutung im Context Nutzerprofil |
| --- | --- |
| Nutzerkonto | Lokaler Eintrag in Knitventure, der einer Anmeldeidentität zugeordnet ist und über den das eigene Profil wiedergefunden wird. |
| Anmeldeidentität | Die vom Anmeldedienst bestätigte Identität, anhand derer Knitventure das zugehörige Nutzerkonto erkennt. |
| Nutzerprofil | Die in Knitventure gepflegten Angaben zum Nutzerkonto. Im Durchstich gehört dazu der Avatar. |
| Avatar | Das Bild, das eine angemeldete Person für ihr eigenes Nutzerprofil hochlädt oder ersetzt. |
